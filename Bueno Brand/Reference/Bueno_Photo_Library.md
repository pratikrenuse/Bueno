# Bueno Photo Library

The approved Bueno lifestyle photography set. All images are pure photography with no text baked in, warm golden light, Mediterranean settings, subjects roughly 40 to 70. Use these for guides, landing pages, ads and PDFs instead of sourcing new stock.

Pratik supplied these on 4 September 2026. Binary files cannot be stored as project docs, so this file is the catalogue. The master copies live with Pratik and in the Bueno Canva account. Ask him to attach the ones needed at the start of a session.

## Rules for use

Full bleed or full column width, never small and floated. No text overlays on the photograph itself unless there is real copy space, which only 04 and 08 have. Keep the navy stripe and logo lockup on the same page. One photo per section break at most, so the reading rhythm stays calm.
