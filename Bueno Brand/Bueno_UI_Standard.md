# Bueno UI Standard
*Single reference for all Bueno product, marketing, and interface design. Apply before building or modifying any UI.*

---

## 1. Brand Foundations

| Role | Hex | Usage |
|---|---|---|
| Navy | #010221 | Primary / dark backgrounds / text |
| Light Blue | #CBEFFF | Cards / highlights / assistant bubbles |
| Accent Blue | #5B7FCC | CTAs / links / labels |

| White | #FFFFFF | Digital backgrounds / negative space |
| Gold | #C9A96E | Accent word in headlines (e.g. "SIMPLIFIED") |

**Typography:**
- Primary: FS Siena — all customer-facing output
- Fallback: Georgia, serif

| Element | Style |
|---|---|
| Hero Headline | 60–80pt, Uppercase, Navy or White |
| Section Headline | 28–36pt, Title Case, Navy |
| Subheadline | 18–22pt, Regular, Navy or Accent Blue |
| Body Copy | 10–12pt, Regular, Dark Grey |
| Label / Tag | 8–10pt, Uppercase, spaced, Accent Blue |
| CTA | 11–13pt, Medium, Navy or White on Navy |

**Logo:**
- Full lockup always: BUENO | PROPERTY SIMPLIFIED
- Navy logo on light backgrounds, white logo on dark backgrounds
- Never stretch, rotate, or alter proportions
- Never place on busy photographic backgrounds without contrast

---

## 2. Visual Aesthetic Principles

Premium European minimalism — calm, ordered, confident.

- Generous white / negative space. Never crowded.
- Clear typographic hierarchy. Headlines do the work.
- Warmth through photography, not colour saturation.
- Navy stripe or block = Bueno signature. Always include logo lockup.
- Layout grid: 50/50 or 2/3 split. Never less than 50% branded.
- Photography: couples or individuals aged 40–70, warm golden light, Mediterranean settings, clean European interiors. Never staged or corporate.

---

## 3. Copy Rules (applies to all interface copy)

**Always:**
- Short, natural sentences — each one earns its place
- Start with a scroll-stopping hook or question
- Connect features to emotional benefit (ease, trust, time saved)
- Use proof: fees saved, hours saved, bills reduced
- Hook > Pain > Solution > Relief > CTA structure

**Never:**
- Emojis
- Em dashes
- "revolutionary", "disruptive", "game-changing"
- "banking" or "bank" — use "finance", "account", or "platform"
- Attack or imply competitors negatively
- Fear or penalty-based urgency
- Overpromise or exaggerate

**Tone:** Clean, calm, human, professional. Confident without arrogance.

## 4. C.L.E.A.R. UI Framework

Apply all five pillars before finalising any screen. Score each 0–5 (25 total). Fix lowest-scoring pillar first. Re-check earlier pillars after every change.

### C — Copywriting
Make the benefit obvious in 1–2 seconds (WIIFM). Cut any sentence that breaks nothing if removed. Sound like a person, not a brochure. Specific, active verbs. Reassure near friction points ("You can change this later").

Tests to run:
- Barstool Test: would you say this to a friend?
- Copy Swap Test: could a competitor reuse these exact words? If yes, it is too vague.

### L — Layout
Use Gestalt grouping:
- **Similarity** — same role, same look; reuse components
- **Proximity** — tight spacing within groups, loose between groups
- **Simplicity** — remove styling that carries no meaning; one primary action per region
- **Alignment** — 4px grid; align edges, especially left edges
- **Common Region** — group with cards and sections; subtle fills before heavy borders
- **Continuity** — clear top-left-to-bottom scan path; no zig-zags

### E — Emphasis
Tune six dials: Size, Colour, Space, Placement, Visualisation, Motion. Commit to 1–2 leading dials; let the rest support. Run the Squint Test: blur the screen — the most important element must still dominate. If everything shouts, nothing stands out.

### A — Accessibility
- Design for permanent, temporary, and situational limits
- Every screen: visible without searching, operable without precision, actionable without guessing
- Fitt's Law: big, well-spaced tap targets
- WCAG: minimum 4.5:1 text contrast; never rely on colour alone
- Prevent errors: disable invalid actions, provide undo, confirm irreversible actions

### R — Reward
Match the payoff to the user's dominant emotion:
- **Control** — status, ETAs, confirmations, undo (reduces anxiety, gives safety)
- **Competence** — progress bars, done states, streaks (effort feels rewarded)
- **Recognition** — badges, roles, "verified" (pride, belonging)

30-Second Reward Test: the screen must clearly answer at least one of: "Am I safe? Did I do well? Am I recognised?" Keep rewards proportional — reserve big celebration for real milestones.

## 7. Output Pattern for Any UI Deliverable

1. Run C.L.E.A.R. audit — score each pillar 0–5 briefly
2. Address lowest-scoring pillar first
3. Deliver final code or copy with: one unmissable primary action, benefit-led copy, Gestalt-based grouping, accessible contrast and tap targets, and a fitting emotional payoff
